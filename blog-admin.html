站长投稿

粘贴公众号文章，下载正文文件，登记元数据，发布到博客。

  1. 在公众号编辑器里 全选并复制文章正文（Ctrl/Cmd + A，Ctrl/Cmd + C），回到本页粘贴到下方正文区域；或切换到 Markdown 模式 直接写 Markdown。
  2. 粘贴的内容会被自动净化（剥掉内联样式与多余包装，只保留段落、标题、列表、表格、图片等语义标签），核对标题、日期、标签与摘要。
  3. 点击「生成并下载」：富文本模式下载 posts/<id>.html，Markdown 模式下载 posts/<id>.md，把它放进仓库的 posts/ 文件夹。
  4. 把输出区里的元数据行粘贴到 posts.js 数组的最前面（可连续转载多篇，一次性粘贴）。
  5. git add、commit 并 push 到 GitHub，几分钟后文章即上线。
