# 文字切换与浏览性能优化 · 2026-10-10

## 实现

基线为远端 `c94d8e3`，在独立源码副本中实施，未修改文章、数据模型、CMS、联系方式或地址。

- 语言切换改为可见区块 70ms 淡出、170ms 淡入与最多 12px 位移；不调用全页 View Transition、不动画高度。位置读操作集中在文字更新前后，保留可见阅读锚点。最后选择立即保存；取消、导航及减少动态效果会提交待更新状态并取消过期视觉效果。
- 主题仍从按钮中心扩散，普通页面保留原过渡；这次优化不通过取消全部动画来改善性能。
- 相同正文与语言的翻译初始化直接复用，避免导航 after-swap/page-load 连续重复遍历及更新 DOM；文本只在实际变化时改写。
- 视口事件合并到一帧，只写变化的 CSS 值；仅紧凑导航模式变化时通知菜单。软键盘和滚动事件不再重复播放关闭动画，保留安全区与分段布局。
- 指针进入时缓存卡片边界，后续移动复用；高光使用固定渐变位移，不逐帧重绘渐变中心，去掉跟随过程中的 transform 补间滞后。
- 大型首页/产品面板改为静态玻璃底色，导航和弹层保留较小范围模糊；标准/强调模糊从 16/20px 降为 10/12px。首页首屏移除约 400ms 延迟入场，内容直接呈现，保留后续区块单次入场。
- 文章阅读进度缓存几何信息，用二分查找章节；滚动帧不读取所有标题位置，只有尺寸、图片或语言变更时重算，目录状态只在章节变化时更新。
- 新增按钮图标位移、链接下划线展开和空搜索结果淡入；筛选标签集合预解析，动效保持按需执行与减少动态效果兼容。

## 验收

构建及内容测试通过；Chrome、WebKit、Firefox 覆盖既有视口/中英/明暗、键盘菜单、图片弹层、搜索、前进后退、快速交替选择、200% 文字及减少动态效果。新增测试确认语言切换的全页快照调用为 0，重复 VisualViewport 事件不会关闭打开的菜单。

分段模拟等待合并后的下一帧，随后检查按钮边界；首页减少动态效果检查改为直接检查 `.hero-copy`，不再等待已删除的 `.reveal` 类。第一项全站循环测试设 90 秒总上限，单个交互断言不放宽。

## 本地性能对比

使用 `scripts/measure-interaction.mjs`。基线与新版均为固定本地静态资源，远端微信图片使用相同 SVG 替代；无网络限速，排除网络差异。Chrome 无头模式、1440×900、DPR 2、CPU 4 倍减速；每种场景五轮交替冷上下文，待首屏稳定后采样。记录 CDP 主线程 TaskDuration、脚本、布局和样式计算时间，以及计数。

首页：8 次语言切换、60 次连续相同视口事件、40 帧合成指针事件；文章：60 帧滚动。合成指针事件不等同真实悬停绘制，物理鼠标悬停由功能测试另行验证。数据不是实际设备帧率、线上 INP 或用户群体指标，不能保证每台设备获得相同改善。

| 场景     | 基线主线程耗时 | 新版主线程耗时 |    变化 |
| -------- | -------------: | -------------: | ------: |
| language |       371.59ms |       225.05ms | -39.44% |
| viewport |         2.74ms |         2.15ms | -21.49% |
| pointer  |        29.84ms |        27.25ms |  -8.67% |
| scroll   |        37.72ms |        38.49ms |  +2.03% |

文字切换样式计算 136.19→36.85ms（约 -73%），布局次数 96→31；60 次同值视口事件的通知 60→0，脚本时间 1.61→0.10ms。文章滚动总体耗时 +2.03%，没有显著改善或退化，样式计算 3.10→1.66ms；这项主要降低后续较长文章的重复计算风险，不宣称总体滚动耗时大幅降低。

原始五轮样本见 `interaction-performance-2026-10-10.json`。全部 28 项 E2E 场景已通过（最后首屏测试移除旧选择器后单独重跑），5 项内容测试通过，构建 0 错误/警告/提示；首屏截图人工核对，最终相关 7 项交互复查通过；实际指针点击测试中文字切换的阅读锚点误差 0.5px（Chrome）。测试为浏览器与视口模拟，不是真机验收。
