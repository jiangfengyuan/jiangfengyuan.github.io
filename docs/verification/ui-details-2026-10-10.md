# UI 细节与有限动效验收 · 2026-10-10

基线：最新远端 `3e9339f`。内容、文章地址、项目资料和 CMS 不变。

## 新增细节

- 移动菜单链接逐项入场（180ms，16ms 间隔）；关闭/重开取消上一轮，页面销毁清理，减少动态效果即时取消。
- 导航当前页与键盘焦点下划线；主题图标转向；站点标点轻移；作品标题/媒体箭头、文章序号及焦点箭头短促反馈；目录当前章节加下划线。
- 联系区与页脚提供复制邮箱、勾选反馈和双语 live status。失败保留手动复制说明，未写入不显示成功；正在复制不重复发起；页面切换清理计时器。
- 页脚返回页首支持键盘、正文焦点和减少动态效果；无脚本保留普通锚点与邮件链接，隐藏不可用的复制按钮。
- 页脚入口允许换行，修复新增入口在 320px / 200% 字号时横向溢出。
