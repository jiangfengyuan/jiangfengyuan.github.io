# 空间玻璃、响应式布局与动效验收 · 2026-10-07

## 范围与实现

迁移基线为远端 `9cffa0c`。采用原生 CSS、TypeScript 和 Astro ClientRouter，未添加动画框架。三档玻璃、静态柔光、指针高光与倾斜集中在 `src/styles/spatial.css`、`src/scripts/spatial.ts`；切换、取消、共享媒体和生命周期由 `src/scripts/motion.ts` 协调。文章内容、日期、地址、数据模型与 CMS 配置没有改动。

主题通过按钮中心扩散 420ms，语言按可见区块淡化与重排 240ms；页面 280ms，按压 160ms，菜单与弹层 240ms，筛选底板 220ms、结果 200ms，区块入场 400ms、错峰上限 200ms。首次恢复偏好直接应用，连续操作取消旧视觉效果、立即保存最后选择；导航优先于局部动画。相同图片的 Cloud Republic/DHGT 使用共享媒体，Flash 的不同展示图使用普通页面过渡。

展示容器上限 1440px，文章维持 720px；卡片按最低约 320px 自动增列。支持安全区、动态视口、低高度横屏、VisualViewport 软键盘尺寸。识别到物理屏幕间隙时选择面积最大的连续可用区域，导航和弹层避免跨越铰链；无间隙或 API 不可用时采用普通响应式布局。没有按机型名称推测硬件尺寸。

## 浏览器与布局

- Chromium：Chrome 155.0.8059.40；WebKit：Playwright WebKit 26.6；Firefox：Playwright Firefox 155.0。
- 三浏览器均检查 12 个页面、中英文，视口为 320×780、360×800、390×844、430×932、600×840、720×720、768×1024、820×1180、1024×768、1200×800、1440×900、1920×1080、2560×1080、3440×1440、844×390。全站没有横向溢出，语言、主题及菜单按钮为 44px。
- 明暗主题的 WCAG A/AA 自动检查涵盖首页、作品、写作和文章。既有测试覆盖全部页面及九篇文章的图文比例、目录、元数据与阅读字号。
- 三浏览器检查 320/768/1440px 的 200% 文字放大；修复品牌与工具控件换行、首页 flex/grid 最小宽度。长链接、表格与代码沿用文章专项验证。
- DPR 1 为常规布局测试，DPR 2 为性能测试，DPR 3 为触控与分段测试。双段、三段及上下分段均为注入 API 的能力模拟，检查可见控制按钮边界；未使用任何实际折叠屏、平板或显示器真机。
- 软键盘为 VisualViewport 高度模拟，弹层关闭按钮可达；禁用脚本时主要页面、文章正文和导航可用。

Firefox 在本机 macOS 测试时受到原有应用数据目录保护的影响，使用临时下载的测试浏览器、独立应用名称和临时启动器隔离测试。未使用真实 Firefox 用户配置、未授予完整磁盘访问权限；默认测试配置不依赖该启动器，可通过 `PLAYWRIGHT_FIREFOX_EXECUTABLE` 在本机指定。参见 [Playwright #42768](https://github.com/microsoft/playwright/issues/42768)。

## 交互与降级

快速交替切换语言和主题、动画中导航、前进后退、筛选/搜索、键盘菜单、Escape、焦点返回、图片放大和关闭均通过。减少动态效果在动画中启用后，活动动画为 0，最后状态保留。缺失 View Transition API 时局部淡化可操作；强制颜色模式实际模拟为实色、无模糊。无模糊支持及减少透明度采用 CSS 能力查询与媒体查询降级，未声称测试旧版浏览器或操作系统透明度设置。

区块入场单次执行，离屏暂停，导航时清理观察器及动画；指针移出取消待执行帧。首页加载稳定后测得运行中的动画为 0，无常驻动画循环。最终桌面、手机暗色和主题扩散中间帧已人工核对。

## 性能

初次未压缩静态服务器诊断中，文章 LCP 恶化约 11.6%，超过阈值；随后清除旧玻璃与已删除观察器的重复样式，标准/强调模糊降为 16/20px、手机首页降为 8px，首次图片保留直接绘制。

最终比较使用两套相同 gzip 服务器：旧版从 `9cffa0c` 构建产物快照提供，新版为最终产物。Chrome 无头模式、390×844、DPR 2、CPU 4 倍减速、150ms RTT、1.6Mbps 下载、750kbps 上传；每页五轮交替冷上下文，取中位数。微信远端图片在两版均替换为相同 SVG，不能代表微信图片实际网络表现，也不能代替线上用户指标或真机性能。
